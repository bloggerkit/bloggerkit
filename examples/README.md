# Examples

Examples are grouped by the package they show, like `packages/`. Each one is a workspace package named `@examples/<package>-<example>`, run with its own `dev` and `build` scripts.

## [blogger-hbs](../packages/blogger-hbs/core)

- [starter](./blogger-hbs/starter): a theme with templates, data, styles, scripts and Lucide icons.

## [blogger-plugin](../packages/blogger-plugin)

- [react](./blogger-plugin/react): React with Vite.
- [svelte](./blogger-plugin/svelte): Svelte with Vite.
- [vue](./blogger-plugin/vue): Vue with Vite.
